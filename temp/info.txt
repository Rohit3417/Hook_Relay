Circuit Breaker concept :
if a destination server fails continuously (the guide says 50 consecutive failures),
stop sending it traffic entirely for a while — trip to PAUSED/open state. 
This protects two things: your own worker pool (stop burning goroutines/connections retrying something clearly dead)
and the destination server itself (stop hammering a service that might be down for maintenance and recovering).
Closed — normal operation, requests flow through. On repeated failures, trips to Open.

Open — requests are rejected immediately, without even attempting the call — 
       this is the whole point, avoiding wasted work on something known-broken. 
       After some cooldown period passes, transitions to Half-Open.

Half-Open — allows exactly one (or a small number of) trial request through. 
            If it succeeds, transitions back to Closed (recovered). 
            If it fails, goes back to Open (still broken, reset the cooldown).
